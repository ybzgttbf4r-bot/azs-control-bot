# АЗС Контроль

Telegram-бот для проверки очередей и наличия топлива на АЗС.

## Файлы

- `bot.py` — основной код бота
- `requirements.txt` — зависимости Python
- `render.yaml` — настройки для Render

## Запуск на Render

1. Создать Web Service или Worker.
2. Подключить GitHub-репозиторий.
3. Добавить Environment Variable:

`BOT_TOKEN=твой_новый_токен_от_BotFather`

4. Start command:

`python bot.py`
